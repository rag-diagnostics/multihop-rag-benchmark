# Add this README design to your repository

1. Copy `README.md` into the repository root, replacing the current README.
2. Copy all three SVG files from `assets/readme/` into the same relative folder in the repository.
3. Commit the README and the `assets/` folder together, then open GitHub to check rendering.
4. Edit the repo's About section and add a one-sentence description and research topics.
5. When the paper has a public URL, link it at the top and insert the official citation near the bottom.

Visual assets are original static SVG designs with no scripts, remote dependencies, or external fonts. They are scalable and editable.

The three images are conceptual illustrations; the README explicitly marks the B3 image as a sample random arrangement and does not invent new model-performance measurements.

Note: The uploaded README included `CITATION.cff` in its listed tree, but the public repository listing showed a supplementary PDF and no `CITATION.cff` when checked. The replacement README avoids claiming the citation file exists. The original shell example used `--dry-run`; the replacement marks that as validation and explains that it should be removed for actual inference.
