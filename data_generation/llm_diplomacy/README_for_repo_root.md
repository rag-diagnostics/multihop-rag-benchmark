## LLM Diplomacy game generation

Code, setup requirements, prompt provenance, and API instructions for the LLM-played Diplomacy source-data stage are documented in [`data_generation/llm_diplomacy/`](data_generation/llm_diplomacy/README.md). The simulation engine is an external, attribution-required dependency (GoodStartLabs/AI_Diplomacy); its dataset-generation licence restrictions must be clarified before reproducing this stage. This repository does not include raw game outputs or the separate Gemini 2.5 Pro narrative-conversion script.
